# Lumen

A calm, gamified daily Bible reading habit for iPhone. Five minutes, a short stack of illustrated Scripture cards, a quick check, and a little sheep whose meadow gets brighter each day you read.

"Lumen" is a working name. To rename or restyle the app, edit `Lumen/Brand/Brand.swift` (name, colors, fonts, placeholder prices) and `Lumen/Brand/Copy.swift` (all UI copy, English and Spanish). The only other places the name appears are the display name and URL scheme in the Xcode build settings and `Config/Info.plist`.

## Run it

1. Open `Lumen.xcodeproj` in Xcode 16 or later.
2. Pick an iPhone simulator (iOS 17+) and press Run.

No packages, no backend, no keys. Data is stored locally with SwiftData.

To walk the whole loop quickly, open **Settings > Simulator tools**: *Jump to tomorrow* advances the day so you can build a streak, *Skip a day* misses one so you can see the lost-sheep recovery, *Toggle Premium* opens Focus Mode, and *Reset everything* returns to the welcome screen.

## Content and translations

Seeded content is `Lumen/Resources/content.json`, generated by `tools/build_content.py`. Scripture text is never typed by hand; the script pulls it from public-domain sources:

- KJV and Reina-Valera 1909: `scrollmapper/bible_databases` (`formats/json/KJV.json`, `SpaRV.json`)
- World English Bible: npm package `world-english-bible`

```
python3 tools/build_content.py KJV.json SpaRV.json world-english-bible/json
```

Each verse card stores its text keyed by translation id (`"KJV"`, `"WEB"`, `"RV1909"`), and translations are declared with a `license` field. Adding NIV, ESV or RVR1960 later means adding a loader, a translation entry and another key. Views do not change.

Explanations and quiz questions in the script are study aids written for this app. They are labeled "Study aid" in the UI, stay close to the text and avoid denominational positions. They should get a theological review before release.

## Finishing Focus Mode

1. Add the Family Controls capability (already in `Config/Lumen.entitlements`) and an App Group shared by the app and extensions.
2. Add three targets in Xcode and use the files in `Extensions/`: Shield Configuration, Shield Action, Device Activity Monitor.
3. From the app, write today's reference, verse and the saved app selection to the App Group, and start a repeating daily `DeviceActivitySchedule`.
4. Distribution requires Apple's Family Controls entitlement approval.

## Art: every asset that needs final illustration

Every illustration is an `ArtLayer` (or `SheepView`) that looks up an image by name in `Assets.xcassets` and falls back to a painted placeholder. Add an image with the exact name below and it replaces the placeholder with no code change. Style: hand-painted gouache with paper grain, pastel sky in peach, blush and pale aqua, golden rim light. No halo or crown on the sheep.

## Research notes

Screens of Scroll The Bible, BibleScroll, Manna and Duolingo were reviewed in Appllama before building. What carried over as principles:

- **One obvious next action.** BibleScroll's home is a single "Read Bible to Unlock" button. Lumen's home has one primary button too.
- **Tap a verse to understand it.** Scroll The Bible's study sheet is its best idea, but it sits on a plain white feed that never ends and its streak only counts days opened. Lumen keeps the study sheet, gives every session an end, and ties the streak to finishing a reading.
- **A path gives a plan a shape.** Manna and Duolingo both show progress as a path of nodes. Manna's flat, bright cartoon style and hearts system feel like a children's game, so Lumen uses a quiet painted map, no hearts and no penalties for wrong answers.
- **Streaks work, guilt does not.** Duolingo's streak, freezes and friend streaks are effective but lean on loss. Lumen keeps freezes and a weekly league, replaces fire with light, and frames a missed day as a sheep to bring home.
